ABOUT THIS PROJECT

Mijn media skills in de praktijk

Voor een van mijn laatste opdrachten binnen de opleiding moest ik een media uiting maken. Hierin moet ik laten zien wat ik kan binnen de media. Ik besloot een video te maken over het edit werk dat ik kan doen.

Mijn taken:
– Filmen (Sony A7SII en DJI Mini 3)
- Edit (Davinci Resolve)
– Color grading
- Effecten in Fusion

Deze video laat zien wat ik in korte tijd kan filmen en monteren (zoals studenten vaak doen, had ik het project een beetje uitgesteld). Het combineert mijn technische vaardigheden met creatieve storytelling en laat zien dat ik zoiets volledig zelfstandig kan maken.
